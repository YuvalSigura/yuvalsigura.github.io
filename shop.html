How this becomes real

Store later. Brand now.

Can this sell products already?

Not yet. No payment provider or print-on-demand account has been connected, so the page intentionally shows concepts rather than pretending products are available.

What can be connected later?

Printful, Printify, Fourthwall, Shopify, Etsy or another store can provide the actual checkout. The GitHub Pages site can then link directly to each product.

Do we need to redesign it?

No. Product images, prices and buy links can be dropped into the existing cards.
